# Documentación del Proyecto

En esta carpeta se encuentra la documentación asociada al proyecto, la cual se organiza de la siguiente forma:

- `investigacion`: Aquí se agrupan los informes y documentos
- `bosquejos`: Contiene los bosquejos, borradores y prototipos

El propósito es separar la información de investigación y análisis de la información visual del proyecto.

La estructura puede cambiar a medida que avanza el proyecto.
